# Wallet Solana

Web wallet Solana sederhana — semua berjalan di browser, kunci tidak pernah dikirim ke server mana pun.

## Fitur

- Cek saldo alamat Solana di mainnet
- Buat wallet demo (kunci dibuat di browser kamu)
- Airdrop dan kirim SOL di devnet (uang mainan, untuk belajar)
- Kirim di mainnet dikunci demi keamanan
- Panduan mengubahnya jadi aplikasi APK (Flutter + GitHub Actions) ada di dalam halaman

## Cara pakai

1. Buka `index.html` di browser HP atau komputer.
2. Buat wallet baru atau impor kunci yang sudah ada.
3. Simpan kunci rahasiamu di tempat aman — jangan pernah dibagikan ke siapa pun.

## Keamanan

- Kunci privat hanya tersimpan di browser kamu sendiri.
- Jangan pernah mengirim seed phrase atau kunci privat ke siapa pun, termasuk ke pembuat wallet ini.
- Wallet demo / devnet hanya untuk belajar — jangan simpan dana besar di wallet yang dibuat untuk coba-coba.

## Cara jadi APK

Panduan lengkap mengubah wallet ini menjadi aplikasi Android (APK) memakai Flutter dan GitHub Actions ada di dalam halaman wallet itu sendiri.

---

English summary: a simple Solana web wallet. All keys stay in your browser; nothing is sent to any server. Check mainnet balances, create a demo wallet, airdrop and send SOL on devnet. Mainnet sending is locked for safety.
