Halaman ini tidak menyimpan seed phrase / private key kamu di mana pun. Jangan pernah tempel seed phrase ke situs apa pun, termasuk ini.

✓ Jalan ke APK jelas

GitHub itu tempat naruh kode. Yang mengubah kode jadi APK adalah Flutter + GitHub Actions — struktur folder & contoh konfigurasinya sudah disiapkan di bawah.

Jujur dulu ya, cuy: ini versi web dari wallet-nya, bukan APK final. Kirim SOL beneran jalan di devnet (uang mainan) pakai wallet demo di bawah. Dari halaman ini jadi APK beneran

GitHub bukan yang bikin APK — GitHub tempat naruh kodenya. Urutannya begini, dan ini yang dipakai programmer beneran:

1
Bikin repo di GitHub

Repo baru, misal wallet-solana di akun GitHub kamu. Semua kode wallet ditaruh di sini.

2
Tulis kode pakai Flutter

Satu kode bisa jadi Android + iOS. Buat Solana, pakai paket solana di pub.dev buat bikin kunci, cek saldo, dan tanda tangan transaksi.

3
GitHub Actions build APK

Tiap kode di-push, GitHub otomatis nge-build file .apk-nya. Kamu tinggal download dari tab Actions — tanpa perlu laptop kencang.

4
Install & uji di HP

Download APK, install, uji pakai devnet (uang mainan) dulu. Jangan langsung mainnet sebelum kode dicek orang yang paham keamanan.

wallet-solana/ ← repo GitHub kamu ├─ lib/ │ ├─ main.dart ← layar wallet (mirip pratinjau di atas) │ ├─ wallet_service.dart ← bikin kunci, cek saldo, kirim SOL │ └─ secure_store.dart ← simpan kunci terenkripsi di HP ├─ android/ ← pengaturan Android / APK ├─ pubspec.yaml ← daftar paket (termasuk paket solana) └─ .github/workflows/ └─ build-apk.yml ← resep otomatis bikin APK di GitHub
# .github/workflows/build-apk.yml — contoh resep build APK
name: Build APK
on: [push]
jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: subosito/flutter-action@v2
      - run: flutter pub get
      - run: flutter build apk --release
      - uses: actions/upload-artifact@v4
        with:
          name: wallet-solana-apk
          path: build/app/outputs/flutter-apk/app-release.apk

Catatan jujur: file di atas adalah contoh kerangka, bukan APK jadi. Supaya beneran bisa di-download jadi APK, repo Flutter-nya harus dibuat dan di-push dulu — halaman web ini adalah prototipe tampilan + logika cek saldonya, yang nanti dipindah ke main.dart.

Aturan aman — ini yang paling penting

Wallet itu pegang duit beneran. Sekali kuncinya bocor, duitnya hilang dan tidak bisa dibalikin — tidak ada bank yang bisa nolong.

Seed phrase = kunci rumah

12/24 kata rahasia itu satu-satunya kunci wallet. Tulis di kertas, simpan di rumah. Jangan difoto, jangan dikirim ke chat, jangan diketik di situs mana pun.

Alamat publik boleh dibagi

Alamat kayak 2h7bk…T1CmU itu aman dibagikan — orang cuma bisa kirim ke situ dan lihat saldonya, tidak bisa ngambil isinya.

Uji pakai uang mainan dulu

Solana punya devnet: koinnya gratis dan tidak berharga. Semua versi awal wallet wajib diuji di sana dulu sebelum nyentuh mainnet / duit asli.

Wallet Solana — versi web yang bisa langsung dicoba. Saldo dibaca langsung dari Solana mainnet saat kamu menekan “Cek saldo”; kirim/terima jalan di devnet pakai wallet demo. Halaman ini tidak menyimpan alamat, kunci, atau data apa pun setelah kamu menutupnya — kunci wallet demo hilang pas halaman ditutup, makanya jangan kirim duit asli ke alamat demo.
